# Examples

`reference_output/readiness.md` is an anonymised readiness report from a real SAP BDC
tenant, included so you can see the shape of the output before committing to a run.

Every figure in it is a measurement from that one tenant. Yours will differ - the point
of the assessment is that it measures *your* share rather than assuming this one
generalises. What does generalise is the set of checks and the interpretation of each
verdict, which is documented in [../docs/deployment.md](../docs/deployment.md).
